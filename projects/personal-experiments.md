Ajay keeps a public set of small interface experiments alongside product work.

- Nots: a browser-based, black-screen notes tool.
- Gift LLM Tokens: a concept interface for gifting API tokens or subscriptions.
- PulseKey: a live validator for AI-provider API keys.
- Moodz: a voice-reactive 3D visualizer with mood presets and ambient audio.

These experiments are useful references for prototyping, interaction design, and testing ideas quickly. Verify each live project before assuming it remains available or unchanged.
