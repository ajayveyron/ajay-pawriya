# Memory records

Each record is a small, dated statement of context rather than a raw conversation dump. Use folders when the collection grows, for example `work/`, `projects/`, `people/`, or `preferences/`.

Required frontmatter fields:

- `type`
- `title`
- `updated` in `YYYY-MM-DD` form
- `confidence` as `high`, `medium`, or `low`
- `privacy` as `private` or `restricted`
- at least one `sources` item

Do not store credentials, access tokens, or sensitive personal records here. Delete or revise facts only with an explicit user request and preserve a concise source trail.
